# Telegram-бот «Хоккейный календарь»

Локальный личный Telegram-бот для хоккейного календаря: события, справочники, расходы, статистика, уведомления и Excel-экспорт.

## Архитектура

- `bot/` — Telegram handlers и inline-клавиатуры.
- `core/` — конфигурация приложения.
- `db/` — SQLAlchemy engine/session и инициализация SQLite.
- `models/` — таблицы и enum-модели предметной области.
- `services/` — бизнес-логика событий, справочников, статистики, валидации и представления.
- `notifications/` — расчёт расписания уведомлений с учётом часового пояса.
- `excel/` — генерация `.xlsx`.
- `tests/` — быстрые тесты сервисного слоя.

## Запуск локально

```bash
cd /workspace/InvoiceCreator
python -m venv .venv
. .venv/bin/activate
pip install -r hockey_bot/requirements.txt
export TELEGRAM_BOT_TOKEN="..."
export ALLOWED_TELEGRAM_USER_ID="123456789"
python -m hockey_bot.db.init_db
python -m hockey_bot.main
```

По умолчанию используется SQLite-файл `hockey_bot.db`. Для будущего VPS/PostgreSQL можно задать `DATABASE_URL`.

## Реализованная основа первой версии

- Схема БД: пользователи, команды, история собственной команды, лиги, связи лига-команда, арены, сезоны, события, повторения, расходы, уведомления.
- Исторические snapshot-поля в событиях сохраняют старые названия команд, лиг, арен и сезонов.
- Soft delete и восстановление событий через `deleted_at`.
- Архивация справочников через флаг `archived`.
- Повторяющиеся тренировки создаются отдельными событиями.
- Автоопределение победы/поражения по счёту `Хозяева:Гости` с запретом ничьих.
- Финансовая и спортивная статистика.
- Расчёт уведомлений: за день в 12:00 и за 3 часа; если первое время уже прошло, оно не создаётся.
- Excel-экспорт с листами из ТЗ.
- Telegram-точка входа с авторизацией по `ALLOWED_TELEGRAM_USER_ID` и главным меню на русском.

> Полные пошаговые FSM-сценарии Telegram-форм добавления/редактирования намеренно отделены от бизнес-логики и могут расширяться поверх готовых сервисов без смешивания SQL, доменной логики и handlers.
